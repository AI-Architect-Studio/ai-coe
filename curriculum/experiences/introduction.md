# Introduction · 90 minutes

For a first-time operator with one recurring decision. The learner owns a local folder, the quickstart prerequisites and a copy of the source card. The facilitator has a clean checkout and the [synthetic case](../worked-case.md). Collect the [pre-assessment](../participant-workbook.md) before class.

| Elapsed minutes | Exercise | Observable output |
| --- | --- | --- |
| 0–10 | Describe the decision and write an unaided recommendation | Dated initial decision and review criterion |
| 10–25 | Choose a blueprint, inspect the proposed workspace, authorize local setup | Configured workspace and logged tool choices |
| 25–45 | Complete the quickstart mission and inspect its artifact | Output reference and first recorded run |
| 45–60 | Apply the worked case to a decision brief | One claim traced to a source, one material uncertainty |
| 60–75 | Swap reviews, introduce the corrected activity log, revise | Retained first draft and justified second decision |
| 75–90 | Explain a human override and schedule a comparable run | Individual defense and one-week roadmap |

The facilitator asks the learner to show where a downstream reader would find the conflicting evidence. Accept the source-backed decision and its working local context separately. Record any pending installation. The 90-minute session can demonstrate one judgment under changed inputs. Longitudinal improvement requires another observation.
