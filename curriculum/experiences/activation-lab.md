# AI CoE Activation Lab · four hours

For a process owner who can bring two shareable examples of the same task. Bring a writable workspace, the quickstart toolchain and one peer reviewer. Complete the [workbook](../participant-workbook.md) pre-assessment and time one previous run where evidence exists.

| Elapsed minutes | Exercise | Artifact |
| --- | --- | --- |
| 0–30 | Write a contract for one recurring job and the human acceptance boundary | Frozen first decision and measurable completion condition |
| 30–75 | Configure a blueprint, remove an unnecessary integration, run mission A | Config diff and source-linked result |
| 75–105 | Peer reconstructs the decision from local records | List of missing context and one corrected decision record |
| 105–120 | Break and prepare second case | Agreed failure condition |
| 120–165 | Remove a required source or approval and repeat on case B | Held/revised result with reason, original run preserved |
| 165–205 | Propose a recovery step, replay from a clean workspace | Recovery receipt and approval state for proposed change |
| 205–240 | Reviewer operates the workflow unaided; learner defends a tradeoff | Observed handoff, revised skill candidate and seven-day follow-up |

Have the facilitator give the reviewer only the workflow and source references. Track steps requiring verbal help. A passing operational handoff yields an accepted artifact or a justified hold with a clear resumption condition. The learner must explain which task needs a person when the case changes.
