# Worked case · The rehearsal room

All evidence below is synthetic. Share the first table before revealing the answer key. A fictional founder is deciding whether to build a booking integration for independent rehearsal rooms. Participants may adapt this as their first mission brief or use it alongside the repository's built-in example.

| Source | Permitted use | Observation |
| --- | --- | --- |
| S1, interview note, day 1 | Private class exercise | A venue manager manually reconciles cancellations every Friday. They would try a weekly exception list. |
| S2, operator log, day 3 | Private class exercise | The venue logged 12 cancellation edits in four weeks. The log contains no times per edit or rates of payer conversion. |
| S3, trial policy, day 4 | Private class exercise | The operator may prepare a local sample from synthetic records. Production booking writes, outreach and purchases need separate approval. |
| S4, peer interview, day 5 | Private class exercise | A second venue uses a spreadsheet and reports that cancellations are rarely a problem. |

**Learner brief.** You have 25 minutes and zero external spend. Choose the cheapest next decision the evidence can support. Draft one page with the beneficiary, one versioned source per material claim, proposed test, one observable disconfirming result, decision owner and permitted next action. Another operator should be able to repeat your reasoning without reading the conversation.

## Facilitator key · disclose after the attempt

A useful decision is a local trial at the first venue. The sample could group cancellation changes for manual review. S1 supports interest in a trial and S2 supports frequency at one venue. S4 limits generalization. S3 permits the local sample. No source establishes willingness to pay, minutes saved or authority to change a booking. An explicit decision to hold is also defensible when it identifies the evidence needed to proceed.

Show the class a deliberately flawed line: “Two venues need automatic cancellation handling, and this will save six hours a month.” Ask the reviewer to mark the exact unsupported phrases and the sources that would settle them. A defensible revision: “One operator offered to review a local exception list. Run the sample and measure review time before deciding whether further work is warranted.”

**Changed condition.** The first operator corrects the log: nine of the twelve edits were scheduled maintenance. Retain the original note, reference the correction, and count three observed cancellation edits. Ask the learner to predict how the lower observed volume changes the proposed trial. Credit a smaller trial or a decision to stop when the reasoning accounts for the new evidence.

**Second transfer.** The trial owner asks for automatic booking updates. Change only the requested action. The workspace may still produce a local review artifact. The actor entitled to permit a production write has not granted approval. A correct answer names the current boundary and leaves any operational change pending.

A cohort can publish an anonymized exercise description with permission. Keep the exercise's fictional results distinguishable from observations of actual learners or businesses.

## Facilitator rehearsal against the executable founder fixture

The bundled founder intake uses a studio handoff case. Use it to rehearse the same teaching mechanism before introducing the rehearsal-room scenario. Work on a private copy of `examples/founder` and two empty workspaces. Run the README dry run and activation on the unchanged intake. The initial brief should say `Disposition: review experiment.`

Now simulate a corrected interview. Replace the text in the copy of `evidence/interview-b.txt` with “We already record and retrieve the vendor rationale during handoff.” Set the matching source's `excerpt` to that exact sentence. Move `interview-b` from the handoff candidate's `supports` list to its `challenges` list. Ask the learner to predict what will change before running the corrected input in the second workspace. This manual classification is a human decision and should be disclosed.

On 25 November 2026, this rehearsal returned `Disposition: resolve conflicting evidence.` Both decisions retained `Decision owner sign-off: pending.` The first dry run created no files in the empty workspace.
