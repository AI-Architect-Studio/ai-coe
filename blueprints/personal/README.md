# Personal AI CoE

Choose one learning practice for the coming week. The owner supplies a goal, candidate actions and attributed observations. The first mission builds a learning decision and exposes both supporting and challenging evidence.

Start with the existing [company-of-one operating template](../../templates/company-of-one/README.md) and the [chief-of-staff role](../../agents/chief-of-staff.md). Use the [shared activation commands](../../README.md#activate-a-workspace) with `"audience": "personal"` in your intake. Review the [blueprint configuration](blueprint.json) for priority domains, suggested skills and decision rights.

At review, answer “What would change my mind after a week of practice?” Sign off locally before assigning a follow-up. Repeat with fresh observations to compare the decision.

The existing [personal CoE architecture fixture](https://github.com/frankxai/ai-architect/tree/1b924d55929bad73cbc44021247c541294316f87/examples/personal-ai-coe/docs/architecture) contains a machine-local runtime decision, task-based routing, a human memory-promotion policy, worked economics and eval cases. Use it when the first personal mission warrants scheduled reading and recall. Its published figures are explicitly illustrative.
