# Enterprise AI CoE

Choose a bounded internal pilot and a named decision owner. The owner supplies a goal, candidate actions and attributed observations. The first mission builds a pilot decision and exposes both supporting and challenging evidence.

Start with the existing [engineering-team operating template](../../templates/engineering-team/README.md) and the [governance-agent role](../../agents/governance-agent.md). Use the [shared activation commands](../../README.md#activate-a-workspace) with `"audience": "enterprise"` in your intake. Review the [blueprint configuration](blueprint.json) for priority domains, suggested skills and decision rights.

At review, answer “Which owner can stop the pilot and which evidence supports expansion?” Sign off locally before assigning a follow-up. Repeat with fresh observations to compare the decision.
