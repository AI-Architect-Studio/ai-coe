# Founder AI CoE

Choose one customer problem for a validation experiment. The owner supplies a goal, candidate actions and attributed observations. The first mission builds a validation brief and exposes both supporting and challenging evidence.

Start with the existing [company-of-one operating template](../../templates/company-of-one/README.md) and the [growth-agent role](../../agents/growth-agent.md). Use the [shared activation commands](../../README.md#activate-a-workspace) with `"audience": "founder"` in your intake. Review the [blueprint configuration](blueprint.json) for priority domains, suggested skills and decision rights.

At review, answer “What behavior would justify another week of investment?” Sign off locally before assigning a follow-up. Repeat with fresh observations to compare the decision.
